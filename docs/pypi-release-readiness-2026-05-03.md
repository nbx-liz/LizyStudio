### 2.2 発見された Bug

#### B-1: `inf/{id}/plot/shap-summary` が 500 を返す（Severity: Medium、**RESOLVED** — Issue #355 / PR #356）

```text
ValueError: Unknown plot type: 'shap-summary'
  File "src/lizystudio/services/inference.py", line 427, in get_inference_plot
  File "src/lizystudio/backends/lizyml/evaluation_mixin.py", line 98, in plot
```

- フロントエンドが `/plot/shap-summary` を自動取得するが、`lizyml` Adapter は SHAP plot を未サポート
- SHAP toggle OFF でも呼ばれており、無条件にリクエストしている疑い
- ユーザ体験: 推論結果は正常に表示されるが Console に 500 が記録される
- **対応方針**: いずれか
  1. Adapter 側で `shap-summary` を実装する (lizyml `explain` extra は依存に含まれている)
  2. Frontend 側で Adapter 能力を取得して条件分岐させる (`/api/backends/ui-schema` 等で plot_kinds を返す)
  3. 暫定: `evaluation_mixin.plot()` で `shap-summary` を空 `PlotData` として握りつぶす

PyPI リリースまでに **(3) 暫定対応** 程度は入れるべき。Console 500 は新規ユーザの初期印象を大きく損ねる。

## 3. アーキテクチャ可視化

`docs/architecture-overview.md` を新規作成。Mermaid で以下 5 種の図を実装ベースで記載:

1. **System Context (C4 L1)** — User / Browser / LizyStudio Server / lizyml / FileSystem / Prometheus
2. **Container View (C4 L2)** — Frontend SPA / FastAPI app / WebSocket Hub / Subprocess Worker / Storage
3. **Module Layering** — pages → components → hooks → api  /  api → services → backends → storage
4. **Job Lifecycle State Machine** — pending → running → (completed | failed | cancelled)
5. **Sequence (×4)** — data load / fit + WS / export / inference run

Tier 1 (`BLUEPRINT.md`) を置き換えるものではなく、初見者向けの導入レイヤーとして機能。
